# Hollow Banner

RPG táctico por turnos. MVP del Acto 1.

**Stack:** Phaser 3 + TypeScript + Vite

## Requisitos

- Node.js 18+
- npm 9+

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Abre `http://localhost:5173` en el browser.

## Build

```bash
npm run build
```

El output queda en `dist/`.

## Preview del build

```bash
npm run preview
```
